# Vonnies Wax & Slijp Service – website

Statische one-pager voor Vonnies: ski’s en snowboards met de hand waxen, slijpen en vullen in Ridderkerk.

- Bekijken: `python3 -m http.server 8000` en open http://localhost:8000
- Beheer met Claude Code: alle afspraken over merk, teksten, prijzen en werkwijze staan in [`CLAUDE.md`](CLAUDE.md).
- Hosting: GitHub Pages (zie `CLAUDE.md` → “Eerste keer opzetten”).
